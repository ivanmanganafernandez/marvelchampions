# TVA Timeline App

Primera versión de una interfaz web inspirada en la TVA.

## Archivos

- `index.html`
- `styles.css`

Abre `index.html` en tu navegador para ver la página.

Las imágenes son temporales y proceden de URLs externas de Unsplash. Puedes sustituir cada valor `src` por tus propias imágenes.

## Vista móvil

La interfaz está adaptada para mostrar las cuatro líneas temporales en una sola pantalla sin desplazamiento vertical.
